# My Little Library

A personal media library app, based on Bartek's Media Lists Movies MVP with permission to reuse and modify.

## Current starter

- React + TypeScript + Vite
- Movie library with posters, ratings, Markdown notes and GitHub-backed storage
- PWA manifest and service worker
- GitHub Pages deployment workflow

## Planned adaptations

- Books, movies and TV shows
- Import the existing personal library and ratings
- Finished dates and 1–10 ratings
- Category-specific statistics
- Custom visual design and mobile-friendly navigation

## Development

Requires Node.js 20+.

```bash
npm install
npm run dev
npm run build
```
